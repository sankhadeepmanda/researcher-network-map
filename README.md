# IIT Mandi Researcher Network

An interactive network visualization tool designed to map, explore, and analyze academic connections, research topic similarities, and collaboration opportunities among researchers at **IIT Mandi**.

---

## 📌 About the Project

The **IIT Mandi Researcher Network** visualizes connections between faculty, scholars, and researchers based on their research domains, publication topics, and shared academic interests. By mapping these relationships, the project helps discover interdisciplinary overlap, potential collaborators, and institutional research clusters.

### Key Features

* **Interactive Network Map:** Visually explore connections and proximity between researchers.
* **Topic & Similarity Analysis:** Group researchers based on shared keywords, domains, and research interests.
* **Scalable Data Architecture:** Built to easily expand from initial cohorts to larger academic groups (e.g., webinar participants, department-wide faculty).
* **Search & Filter:** Find researchers quickly by field, department, or keyword.

## 🚀 Getting Started

### Prerequisites

* A web browser (Chrome, Firefox, Edge, Safari)
* Python 3.x *(if running local processing scripts)*

### Installation & Local Setup

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/iit-mandi-researcher-network.git

```


2. **Navigate to the project folder:**
```bash
cd iit-mandi-researcher-network

```


3. **Run the visualization:**
* Open `index.html` directly in your browser, or start a local HTTP server:
```bash
python -m http.server 8000

```


* Access the application at `http://localhost:8000`.
